# Preflight — 1.18.0

PR: #413
Status: passed
Signed: 2026-10-13 against cf0c254

A small release in size (9 commits, ~65 files) but with three things that production has to be wired
up for: **two migrations** (`20261009120000_perf_dashboard`, `20261013120000_event_types_accountant_select`),
**one PowerSync sync-rule change** in `br_powersync` (a new accountant stream for `EventTypes`, needs a
PowerSync restart), and a rewrite of how the app **connects and uploads** (every read and write now
goes through a timer). The rules are covered by Postgres and unit tests; what they cannot tell you is
whether the real connection still syncs and uploads.

The one merge in the PR (`47c99a8`) joined the perf dashboard to the venue/event-type work. No file
was changed on both sides, so nothing was dropped from a form.

**Deploy in this order**: apply both migrations to production Supabase, then deploy `sync_rules.yaml`
in `br_powersync` and restart PowerSync, then deploy the app. In the other order the accountant's
Event Type line says "Unknown" until the sync catches up; nothing breaks.

**Also, by hand, for the week of Oct 5** (the bug this release fixes already hit it): delete the USA
driver's orphan bill in QuickBooks, press **Mark as Draft** on the Canadian driver who was wrongly
marked **Bill Created**, then create both bills again.

## New in this release

- [x] **A QuickBooks bill goes to the driver you clicked.** In the Development copy, on a QuickBooks
      sandbox connection, open **Work Trackers → a week** with at least one USD and one CAD driver
      who each have trips and a QuickBooks-linked vendor. Set **Currency** to **USD**, then click
      the status button of a USD driver who was _not_ first in the unfiltered list → **Create
      QuickBooks Bill**. That driver's button turns **Bill Created** and its window shows the bill;
      set Currency back to **All**: every CAD driver still reads **Draft**. Repeat once with **See
      All Drivers** / **See My Drivers Only** instead of the currency filter.
- [x] **The same, as an accountant.** Sign in as an accountant and create one bill from the same
      list: it succeeds and that driver reads **Bill Created**. (The server now looks up the week's
      group as the person clicking, so this proves the accountant is not refused.)
- [x] **Copy a venue's address.** Open a quote → **Contract** tab → **Venue**. Hover the copy icon in
      the card's top-right: the tooltip says **Copy address**. Click it: the tooltip says **Copied!**
      and the icon is a green check for about a second. Paste somewhere: one line, street, city,
      state or province and postal code, no stray commas. Click the card itself: the venue's event
      history opens. A long street never runs under the icon.
- [x] **Event Type on the Contract tab.** As an account manager, open a quote that has an event type
      → **Contract** tab: **Event Type: <the type>** sits under **Event Name**. Open a quote with no
      type: it reads **Not set**.
- [x] **Accountants see the event type.** After the migration, the sync rule and the PowerSync
      restart are live, reload as an accountant, open any quote → **Contract**: the same type shows,
      not **Unknown**. **Edit** is still not offered to them.
- [x] **Dev Tools → Performance.** As a developer, open it from the sidebar: four blocks fill
      (Metrics, SQLite calls, Errors, Telemetry health) and switching period, environment or version
      changes the address and the numbers. Use the app for a minute in production, press
      **Refresh**: rows for `powersync.connect`, `ui.first_data` and `sqlite.query` appear for
      version 1.18.0. As an admin, open `/dev-tools/performance` by address: you are sent away.

## Could have broken

- [x] **Sync still connects and uploads.** Right after deploy, hard-reload as an account manager:
      the **Dashboard** fills. Edit one small thing (a note in an empty dashboard cell) and confirm
      the row is in Supabase within a few seconds. Sign out and in again: it reconnects and the
      Dashboard fills. This is the connect/upload path the whole release rewrote.
- [x] **Two tabs.** Open the app in two tabs and edit in one: the other shows it without a reload and
      neither shows an error toast. Close the first tab, edit in the second: it still uploads.
- [x] **Reads that were rewritten.** **Terms & Conditions** lists its templates and opens one with
      its text. A quote's detail page loads, and **Edit** on a quote opens the form with the
      account manager already filled in.
