# Preflight — 1.19.0

PR: #426
Status: passed
Signed: 2026-10-20 against 93879910

Large release (162 files, 5 migrations, 3 merge commits). Deploy order matters: the migrations
and the PowerSync sync rules go out **before** the app, because a write the database refuses is
dropped by the upload queue and shows only as an error toast.

## New in this release

- [x] **Website lead arrives.** POST a sample WPForms body to `/api/webhooks/wpforms-lead` on
      staging with the right `x-webhook-secret` — a New quote appears with the contact, address,
      dates and seats filled in, and its **Submission** tab shows the raw form text. The same
      request with a wrong secret returns 401 and creates nothing.
- [x] **Inbound Leads button.** As an account manager, click **Inbound Leads** (also
      `?template=my_inbound_leads`) — you see only unassigned leads in your zones plus ones
      assigned to you, oldest first, never a colleague's. The red number matches the rows, and the
      header shows "N New Leads!" with a running Wait timer. As an admin you see Zone Unknown and
      unstaffed-zone leads instead.
- [x] **Filters.** In the Filters panel, Inbound (website form) and Zones (several at once, and
      "Zone Unknown") narrow the list and appear as removable chips.
- [x] **Status button.** On a quote's Contract tab click the coloured Status button — a sent
      quote cannot go back to New; **Lost** asks for a reason; picking Booked on a New quote sets
      Signed and the list/log show it.
- [x] **Unsigned Changes.** On a Signed (booked) quote edit the price and save — status flips to
      **Unsigned Changes** by itself and the Signed banner goes. Re-sign via the client link — it
      returns to Signed.
- [x] **Send To Client options.** Send a quote with an extra Cc, a Bcc, a changed subject and one
      attachment removed + one added — the email arrives with exactly those, the PDF is still
      attached, the added file is on the Files tab only after the send, and the Log tab lists
      Cc, Bcc, subject and file names.
- [x] **Quote page follows other tabs.** Open one quote in two tabs, edit the contract in one — the
      other updates without a reload, including the history panels (event, contact, venue) while
      open.
- [x] **Line items save locally.** Edit, add and delete a line item on a quote, save, reload —
      the totals and the contract hash-based banners are right and nothing doubles up.
- [x] **Maintainer.** As a maintainer: Assets → Documents lets you add and edit but shows no
      Delete; Assets → Bleachers can still save a new bleacher with a new type; the header's
      Request a Feature opens `/roadmap/backlog`, where you can submit and edit a ticket and chat
      on it, but cannot delete one or reach the sprint boards.

## Could have broken

- [x] **Merge check — Send dialog and quote form fields.** Create a quote with every field filled
      (contact, venue, dates, seats, notes), save, reopen — nothing was dropped; a field that
      is missing here is the merge-loss pattern.
- [x] **Account manager and viewer on a quote they do not own.** Viewer opens a quote: no Status
      button action, no Send, no edit. Account manager opens a colleague's quote: same read-only
      view.
- [x] **Sending a plain quote** (no changes in the dialog) and **the client signing it** still
      work end to end, and Booked sends its finance notice once.
