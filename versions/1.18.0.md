### 🧾 Work Trackers: a QuickBooks bill could land on the wrong driver

**Work Trackers → a week's driver list → driver's status button → Create
QuickBooks Bill.** If you had filtered the list first (the **Currency** filter,
or **See All Drivers** / **See My Drivers Only**), the bill could be created for
the driver you clicked but marked **Bill Created** on a different driver, whose
bill then wouldn't open. The list now keeps each driver's payment window with
that driver, and a bill is refused if it doesn't belong to the driver and week
it was started from.

⚠️ **If this already happened to you,** the bill is in QuickBooks but the wrong
driver shows **Bill Created**. Delete that bill in QuickBooks, open the wrong
driver's window and press **Mark as Draft**, then create the bill again from the
right driver. Skip the delete and you'll end up with two bills.

### 📋 Copy a venue's address in one click

**Quote → Contract tab → Venue.** A copy icon in the top-right corner of the
venue card puts the address on your clipboard as one line (street, city, state
or province, postal code), ready to paste into a map or an email. It shows
**Copied!** with a check mark for a moment. Clicking the card itself still opens
the venue's event history, as before.

### 🏷️ Quote → Contract tab: the event type

**Quote → Contract tab → under Event Name.** A new **Event Type** line shows
the quote's type, so you no longer have to open the edit form to find it. It
reads **Not set** when none was chosen, and still shows the name of a type that
has since been retired. Accountants see it too, and still can't change event
types.
