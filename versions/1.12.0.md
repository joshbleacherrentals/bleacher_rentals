### 🔧 Annual bleacher inspections, tracked and chased automatically

**Sidebar → Annual Inspections** (admins and viewers; a new role, below, owns
this page). Every bleacher now has an inspection record — a due date, the
certificate, and a note — instead of living in someone's memory or a
spreadsheet. A bleacher is flagged **yellow 30 days before it's due, red at 7
days, and red once it's overdue**, and the list can be filtered down to just
what needs attention.

Recording an inspection is unchanged for account managers — still done from
the bleacher's own edit sheet — but the queue page itself belongs to the new
Maintainer role.

### 👷 A new team role: Maintainer

**Manage Team → + New User.** Maintainer is a role built for one job: owning
the Annual Inspections queue. A maintainer sees Annual Inspections and nothing
else, and they're the only one who gets chased about it — the notification
badge and row highlighting only ever appear for a maintainer, so it reads as a
real to-do list instead of noise everyone learns to ignore.

### ✅ A driver can mark damage already fixed — close it without a maintenance event

**Damage Reports → open a report.** When a driver has already fixed something
themselves, the report now shows **"Fixed by [Driver] on [date]"**, and a
**Mark as Resolved** button sits next to Create Maintenance to Resolve — no
need to invent a maintenance event for a repair that never has to happen.

### 🔁 Duplicate damage reports become one report with a confirmation count

**Damage Reports → open a report.** Drivers who see damage someone already
reported now confirm the existing report instead of filing a second one about
the same thing. That report shows **"Confirmed by N drivers"** with who and
when, so a quiet damage list reads as "handled," not as "nobody's reporting
anymore."

### 🩹 A maintainer-only account no longer shows as an incomplete setup

**Manage Team.** The "Incomplete User Setup" check didn't know about the new
Maintainer role, so a maintainer account looked broken and the banner implied
they couldn't sign in. Fixed.
