### 💲 Editing a quote now keeps the tax up to date

**Quote form → editing an existing quote → Tax.** Opening a saved quote used to
treat its tax as one you'd typed by hand, so changing a price or a line item left
the tax stuck at the old amount. Now the tax follows the rate and the subtotal
unless you type your own, which then stays put and is marked **overridden**.
**Reset to calculated tax** puts it back on automatic. The quote's **Log** tab
records when a typed tax is turned on or off.

⚠️ **Quotes saved before this release all start on automatic tax.** If one of
them had a tax amount typed by hand, it will be recalculated the next time
someone edits it. Retype the amount if you still need it.

### 🎯 Quotes & Bookings: one-click status button

**Quotes & Bookings → top right, next to Show Deleted.** Each click steps the
list through **All Statuses → Booked → Quoted → Lost → Draft** and back to all,
and the button changes colour as it goes. It sets the same Status filter as the
sidebar, which now offers **Draft** too. If you've picked a mix of statuses in
the sidebar, the button reads **Custom Statuses** and the next click starts over
at Booked.

### 🗂️ Open a quote in a new tab

**Quotes & Bookings list.** Every row is now a real link. **Cmd-click**
(Ctrl-click on Windows) or middle-click a row, or right-click it and choose
**Open Link in New Tab**, to open that quote in another tab and keep your place
in the list. Add Shift (Cmd+Shift-click) to jump to the new tab straight away. A
plain click works as before.

### 💬 Messages: the date on every message

**Messages → Internal, and a quote's Messages tab.** Each message now shows the
date before the time, like **Oct 1, 9:44 AM**, so a chat that runs over several
days is easy to follow.

### 🧹 Smaller changes

- **Contact, Venue and Company pickers.** The first click now puts the cursor
  straight in the search box, so you can start typing without clicking a second
  time.
- **Developers: Dev Tools → Allowed Emails.** In the Development copy of the app
  (the one with the green banner), emails only go to addresses on this list, so
  testing can't email real customers or staff. The live app is unchanged. It's
  listed on the **Permissions** page.
