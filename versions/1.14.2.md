### 📍 Dashboard: clicking an event now fills in its venue

**Dashboard → click an event on the grid.** The event form that opens now fills
in the event's Venue, the same way **View in Dashboard** on the quote page
always has. Before this fix, the Venue field came up empty, or sometimes still
showed the venue of the last event you had open.

Whether you click an event on the dashboard or use View in Dashboard from the
quote page, the form now opens with the same details. The **Created date**
(Details tab) now shows either way. Before, it came up blank when you opened the
event from the quote page.

### ⚠️ Events saved from the dashboard may have lost their venue or lost reason

Before this fix, saving an event you had opened by clicking it on the dashboard
could quietly change it:

- **Venue.** The event was unlinked from its venue, or linked to the venue of
  the last event you had open.
- **Lost reason.** On a lost event, the reason and note were wiped.

Events opened with View in Dashboard from the quote page were not affected. If
an event's venue or lost reason looks wrong, open it, set it again and save. It
will now stay.

Also: opening an event now closes any maintenance form you had open, so only
one form is open at a time.
