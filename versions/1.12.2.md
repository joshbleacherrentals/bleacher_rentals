### 🧾 Create Bill no longer risks a duplicate bill on a slow response

**Work Trackers → a driver's week → Create Bill.** If a bill took a while to
finish creating, the page could time out before hearing back — even though
the bill had actually already been created in QuickBooks — and clicking
Create Bill again then created a second one for the same week. Create Bill
now confirms with QuickBooks first and only continues attaching the PDF
after that, so a slow response can no longer lead to a duplicate.
