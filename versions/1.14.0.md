### 📄 Quotes & Bookings list is now paginated

**Quotes & Bookings page.** The list now shows a page at a time (25, 50, or
100 rows), and your page and page size are saved in the link — so reloading
the page, or hitting back from a quote, lands you where you were instead of
back at page 1.

### 🚛 New: Pickup/Dropoff Instructions for events, with a one-click way to reuse the last one

**Quote edit page → under Internal Notes**, and **Work Tracker modal →
Pickup/Dropoff Instructions.** Events now have their own Pickup and Dropoff
Instructions — notes for the driver about that venue: one for delivering
the bleachers before the event, one for retrieving them after. On a Work
Tracker, a new locate button next to each Instructions field pulls the
matching text straight from the nearest event on that bleacher, so you're
not retyping the same directions every time.

Each Work Tracker's Pickup and Dropoff columns also now show a small
**Previous Event / Next Event** card — the event's name and dates, click to
open it in a new tab — so you can see what came before and after without
leaving the modal.

### 🧮 Work Tracker: Pay is now calculated for you, and its tabs stay put while you scroll

**Work Tracker modal → Details tab.** Pay is no longer typed in by hand —
it's always the current line items total, shown once in the footer next to
Delete and Save. The Details/Line Items tabs and the Work Tracker Type
switch also stay pinned at the top of the modal now instead of scrolling
out of view with the rest of the form.

Also fixed: editing only a line item, with nothing else on the trip
changed, used to block Save with "No changes to save." Line item edits now
save on their own.

### 🚫 Attention counts now include bleacher swaps

**Work Trackers sidebar, week view, and driver view.** The red "needs
attention" counts already covered declined and abandoned trips — they now
also include trips run with a different bleacher than the one assigned,
and drop back off the count once the bleachers match. A driver's week shows
the reason next to each flagged trip.

### ⚠️ Alert fixes

- The **"Work Tracker Still in Draft"** alert has been removed — it no
  longer fires, and its warning banner in the modal is gone.

### 🏢 Companies & Contacts: one form everywhere, plus a Company search field

**Company and Contact detail pages, and the Quote form.** Create and edit
now share the same form for each, so nothing you fill in while creating a
contact or company — billing address, shipping address, default venue — is
lost when you go back to edit it later, which used to happen. Company is
now picked the same searchable way as Venue and Contact already were, with
search matching more fields and a "+ Create New" option that's always
reachable even with a long list of matches.

### 🏷️ Quotes: bleacher type description is now copied onto line items

**Quote form → adding a bleacher line item.** The bleacher type's
description is copied onto the line item the moment it's added, so a quote
that's already been sent keeps the wording it was sent with even if the
type's description gets edited afterward.

### 🧑‍💼 Approved quotes now show the client's company

**Quote (web and PDF).** The client's company name and address now show
next to Contact once a quote is approved. When a Finance Contact is set,
the company shown is that contact's, not the main contact's.

### 🖥️ Menus and search popups no longer run off the screen

Across the app — dropdown menus, and the Contact/Venue/Company search
fields in the quote form — a menu near the bottom of the screen used to run
off the edge with no way to scroll down to the rest of it, or close itself
the moment you tried to scroll inside it. These now flip above the field
and cap their height to whatever room is actually there. Notes fields in
the quote form also resize up to 6 lines, and the payment schedule section
has its own labelled button instead of a pencil icon that read as "edit the
price."

### 🧾 Quote → Contract tab: line item numbers fixed

**Quote → Contract tab.** Line item numbers were running together on the
printed/viewed contract; spacing is fixed.
