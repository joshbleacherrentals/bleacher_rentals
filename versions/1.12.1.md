### 🧾 Clearer errors when a QuickBooks bill fails to create

**Work Trackers → a driver's week → Create Bill.** If QuickBooks rejects a
bill — a vendor, work tracker type's account, or tax code that's gone stale
in QuickBooks, or a connection that needs re-authenticating — the error now
says exactly what's wrong and where to go fix it, instead of a generic
"Failed to create bill in QuickBooks." No more guessing which setting broke.
